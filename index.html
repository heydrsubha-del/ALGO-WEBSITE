Explainable detection

From raw message to reviewable findings.

Each stage adds context. The result is a structured lead for investigation, not an automatic accusation or final decision.

  1. 01

    Acquire

    Open a message file, batch, or read-only mailbox session.

  2. 02

    Examine

    Parse headers and content; inspect authentication and suspicious indicators.

  3. 03

    Correlate

    Review route, infrastructure, local memory, and related-case signals.

  4. 04

    Review

    Inspect how each signal supports the weighted risk assessment.

  5. 05

    Report

    Export a traceable summary with limitations and evidence references.

Designed to keep analysis deliberate.

The project is local-first. Email analysis and optional integrations run in the environment hosting the application. This informational site does not accept email uploads or run an analysis.

Read the project privacy notes

  • Local-first by default

    The default workflow stores threat memory locally. Optional network services are described in the project documentation.

  • Mailbox access stays read-only

    The documented IMAP connection does not mark, move, or delete messages.

  • People stay in the loop

    Scores and correlations are investigative leads. A reviewer should assess the evidence and limitations.
